# Lead Manager

A React and Vite multi-business lead management app.

## Theme colors

The visual theme is managed through semantic CSS variables in `src/index.css`. To change the main action color, edit `--primary`, `--primary-hover`, and `--primary-soft` under `:root`; update the matching `:root.dark` values for dark mode. The theme switch follows the device preference by default and saves a manual choice in browser storage.

## Run locally

1. Install dependencies with `npm install`.
2. Start the app with `npm run dev`.
3. Use `npm run lint` and `npm run build` to check the project.
